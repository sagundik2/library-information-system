# Талаптар спецификациясы

## Функционалдық талаптар

| ID | Талап | Сипаттамасы | Басымдық |
|----|-------|-------------|----------|
| FR-01 | Кітапты іздеу | Пайдаланушы атау, автор, ISBN, жанр бойынша іздей алады | Жоғары |
| FR-02 | Кітап қосу/редакциялау/өшіру | Кітапханашы каталогты толықтыра алады | Жоғары |
| FR-03 | Оқырманды тіркеу | Жаңа оқырманды тіркеу, профилін редакциялау | Жоғары |
| FR-04 | Онлайн тапсырыс/брондау | Оқырман кітапқа онлайн тапсырыс бере алады | Жоғары |
| FR-05 | Кітап беру/қайтаруды тіркеу | Кітапханашы операцияны жүйеде тіркейді | Жоғары |
| FR-06 | Мерзімді есептеу және ескерту | Жүйе қайтару мерзімін есептеп, ескерту жібереді | Орташа |
| FR-07 | Есептерді құру | Күнделікті/айлық есептерді автоматты құру | Орташа |
| FR-08 | Пайдаланушыларды басқару | Әкімші рөлдерді тағайындай алады | Орташа |

## Функционалдық емес талаптар

| ID | Санат | Талап | Өлшемшарт |
|----|-------|-------|-----------|
| NFR-01 | Өнімділік | Іздеу сұранысына жауап уақыты | 2 секундтан аспайды |
| NFR-02 | Өнімділік | Бір уақыттағы пайдаланушылар саны | Кемінде 200 қатар |
| NFR-03 | Қауіпсіздік | Деректерді шифрлау | HTTPS/TLS 1.3, парольдер bcrypt |
| NFR-04 | Қауіпсіздік | Рөлдік қатынас | RBAC моделі |
| NFR-05 | Usability | Интерфейс тілі | Қазақша/орысша/ағылшынша |
| NFR-06 | Қолжетімділік | Жүйенің жұмыс уақыты | 99.5% |
