## UC-01: Жүйеге кіру

**Actor:** Барлық пайдаланушылар
**Бастапқы шарт:** Пайдаланушы жүйеде тіркелген
**Негізгі сценарий:**
1. Пайдаланушы «Кіру» бетіне өтеді
2. Логин мен парольді енгізеді
3. Жүйе деректерді тексереді
4. Деректер дұрыс болса, басты бетке бағыттайды
**Нәтиже:** Пайдаланушы жүйеге кірді

## UC-03: Онлайн тапсырыс беру

**Actor:** Оқырман
**Бастапқы шарт:** Оқырман жүйеге кірген
**Негізгі сценарий:**
1. Оқырман «Каталог» бөліміне өтеді
2. Іздеу өрісіне кітап атауын енгізеді
3. Жүйе сәйкес кітаптар тізімін көрсетеді
4. Оқырман қажет кітапты таңдайды
5. Оқырман «Тапсырыс беру» батырмасын басады
6. Жүйе тапсырысты тіркейді
7. Кітапханашыға хабарлама жіберіледі
**Нәтиже:** Тапсырыс «Күтілуде» мәртебесінде сақталды
