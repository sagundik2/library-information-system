# Кітапхана ақпараттық жүйесі

## Жоба туралы
Университет кітапханасының жұмысын автоматтандыруға арналған ақпараттық жүйе.

## Мақсаты
Кітапхана қорын есепке алу, оқырмандарға қызмет көрсету, кітап беру/қайтару операцияларын автоматтандыру.

## Технологиялар
- Backend: Python (Django)
- Frontend: React
- Дерекқор: PostgreSQL
- API: REST

## Құрылымы
- docs/ — жоба құжаттамасы
- diagrams/ — UML диаграммалар
- src/ — бастапқы код
- sql/ — дерекқор схемасы
